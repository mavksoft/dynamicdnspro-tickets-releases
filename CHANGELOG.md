# Changelog — DynamicDNSPro Tickets

All notable releases published in this repository.

## v4.7.41 — 2026-11-24

First public release of the DynamicDNSPro Tickets installer.

- Windows installer for the Tickets app — technical support with an agent
  on the machine: tickets, live terminal, supervised AI and broadcasts.
- Auto-deploy on machines with the DynamicDNSPro Agent when the Tickets
  module is enabled (no installer needed).
- Standalone pairing via link token from the portal's Settings.
