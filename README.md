# DynamicDNSPro Tickets — Releases

Instaladores públicos de la app **DynamicDNSPro Tickets** (Windows).

  (`releases/latest/download/DynamicDNSPro-Tickets-Setup.exe`)
- `DynamicDNSPro-Tickets-Setup-<ver>.exe` → versionado

Los componentes de auto-update viven en `dynamicdnspro-fleet`.
